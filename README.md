- [Logistic Regression with Missing Labels](https://github.com/M-SZEWCZAK/Advanced_ML_project_1) -This project investigates binary classification in the presence of missing labels, with a particular focus on logistic-regression-based methods and experimental comparison under controlled missingness mechanisms, namely MCAR,MAR and MNAR.

- [Borderline-Smote oversampling in random forests](https://github.com/M-SZEWCZAK/Smote_Borderline_RF) - The project focused on using the Borderline-SMOTE oversampling method to train random forests—comparing it to other techniques—to address the common classification challenge of class imbalance, where detecting a critical but rare minority class (such as fraud or disease) is hindered by a dominant majority class.
- [Actions with Cost - extension of Action Language A](https://github.com/SebastianTrojan/krr-action-cost) -  A Knowledge Representation and Reasoning (KRR) solution that implements the $\mathbb{DS}_{4}$ dynamic systems framework to model autonomous agents and their environments. By incorporating a cost metric ($\kappa \geq 1$) into foundational action language logic, the project addresses real-world optimization challenges by evaluating the resource requirements, feasibility, and optimality of specific action sequences.
- [Ecommerce shoppers clustering](https://github.com/qw1mi/ml_pr2) -The main goal of this project was to evaluate some clustering algorithms on a dataset describing web activity of ecommerce platform clients.

- [Me At YouTube](https://github.com/UserKrzysztof/DVT-Project2) - An R Shiny web application designed to analyze YouTube data for three students: Milanna, Krzysztof, and Michał. - [Fast Food Data Analysis Project](https://github.com/fantasy2fry/fast_food_data_analysis_project) - The goal of the project was to analyze food-related data using R language and ggplot package, and create a poster.
